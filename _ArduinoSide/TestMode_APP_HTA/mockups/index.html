FuZz TestMode — HTA visual mockups

Same command console, same command set (Diffuser + SmartTV, every category from the real app), five different looks. Each one is fully clickable — pick a device, select a command, adjust params, hit Send, watch the log — against a small in-memory fake device, not a real socket. Pick whichever reads best and I'll build the real, fully-wired .hta on it.

MOCKUP 1
Refined Graphite
The current dark theme, evolved: deeper layered backgrounds, quiet glow on the selected row/button, subtle card shadows. Lowest-risk pick — closest to what's already there.
MOCKUP 2
Light Studio
Clean white SaaS-dashboard look — soft grey panels, one confident blue accent, gentle shadows. Easiest to read on a bright bench or a projector.
MOCKUP 3
Neon Terminal
Retro hacker / CRT test-rig — near-black, monospace everywhere, neon green primary, faint scanline overlay. Leans into "this is a diagnostic tool."
MOCKUP 4
Glass Aurora
Frosted-glass panels floating over a soft gradient background. Most striking of the five — see the note below on how the blur degrades in the real .hta build.
MOCKUP 5
Mono Card
Near-monochrome, flat, editorial (Linear/Vercel-adjacent) — one accent colour, generous whitespace, almost no shadow.
What these are: visual/interaction mockups only — every Send hits a small in-memory fake device (see shared/app.js) so the UI feels alive, but nothing touches a real UDP/TCP socket yet.

Why not real networking yet: a browser tab (and classic HTA/mshta.exe) can't open a raw socket from script — the old TestMode.hta in this repo's history worked around that by shelling out to udp_send.ps1/tcp_send.ps1 on every send. The real build here will do the same.

One honest caveat: mshta.exe renders with Trident/MSHTML (IE11), not Chrome — so once you pick a look, the real .hta will keep the same layout, colours and spacing, but glass/blur effects (mockup 4) and CSS variables won't render the same way there; I'll translate those to solid, pre-computed colours per theme so the final app still looks right, just without live blur. Flat themes (1, 2, 3, 5) carry over close to 1:1.
