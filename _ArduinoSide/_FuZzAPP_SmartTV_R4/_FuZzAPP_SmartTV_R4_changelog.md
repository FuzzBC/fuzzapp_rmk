| 2.0.0   | 2026-07-23 | Claude | Term console rebuilt on a framed log envelope. Every app-bound log line now goes out as `*` + level(1 hex) + source(2 hex) + seq(2 hex) + text instead of raw `*TEXT`, and all `{#X}` colour markup was removed from the payload - the app colours from the level and tags from the source, so the wire carries data instead of styling. New `APP_LogLevel` (ERR/WRN/INF/DBG plus the layout-only SEC/GAP) and `APP_LogSource` (16 module ids) enums in DEF.h, `APP_LOG_CHAR`/`APP_LOG_HDR`/`APP_LOG_MAX` defines, and `APPx.LogSeq` (rolling per-packet seq the app uses to detect datagrams lost in flight). `formatMSG()` was split into a thin variadic wrapper plus a new `vformatMSG(format, va_list)` core so the new variadic helpers can forward their own argument list without duplicating the specifier parser; behaviour of `formatMSG()` itself is unchanged. Added `APP_Log(level, source, fmt, ...)`, `APP_LogSection(source, fmt, ...)` (titled divider row) and `APP_LogGap()` (blank spacer, replaces the old `APP_Send(formatMSG("*" NL))` lines). `_Debug()` fully rewritten onto these: all 112 `APP_Send(formatMSG("*..."))` call sites are gone, the redundant `MODULE ::` text prefix is dropped (the source id carries it), labels are human-readable lowercase, every value is wrapped in `[ ]` so the app renders it as a chip, RGB triplets are emitted as a single `[r,g,b]` token (the app fills that chip with the actual colour), and level now carries meaning - DBG for constants and table dumps, INF for live state, ERR for a real failure (WiFi down, unknown debug target). Each report is split into named sections (`LED  wiring`, `TV  event log`, `DIFFUSER  idle pulse`, ...) instead of one flat run. Net effect on the wire: ~40 bytes of markup per line removed, replaced by a 5-byte header. Term rows are now three aligned columns - `<clock> [SRC] <message>` - so source tags stack in a fixed lane and a wrapped message re-indents under the body, not under the clock; source names were shortened to four characters (`MOT`, `RAW`, `AMB`) to keep that lane narrow on a phone, and all message text was restyled to read as statements (`Refresh [20] ms`, `Strip enabled [ON]`, `Phone IP [192.168.1.5]`). The severity/source filter chip row was removed from the top of the Term page - level still drives the gutter colour, it is just no longer filterable from the UI. Column spacing corrected: the clock and tag columns had been sized with `android:ems`, but an em is wider than a monospace character advance, so each column reserved roughly a third more width than its text used and left a visible hole before the message.
